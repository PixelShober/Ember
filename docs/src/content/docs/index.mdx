  <Card title="Software über die IT" icon="seti:windows">

  </Card>
  <Card title="Energie, die zur Arbeit passt" icon="rocket">

    ausgeschalteten Zustand. Ein Klick zurück auf die Werkseinstellung geht immer.
  </Card>
  <Card title="Eine Datei fürs ganze Team" icon="document">
    Proxy, Softwareliste und Mailvorlagen stehen in einer `team.json` auf dem Netzlaufwerk. Ändert sich der Proxy,

  </Card>
